## Verified contract

**Config file location:**
`.kiro/hooks/` directory (project-local JSON files, one per hook or grouped).
Rules/steering: `.kiro/steering/*.md`. Specs: `.kiro/specs/<feature>/`.

**Real event names (10 IDE events, verified at kiro.dev/docs/hooks, /hooks/types, /hooks/actions):**
`SessionStart`, `UserPromptSubmit`, `PostToolUse`, `PreToolUse`, `Stop`, `AgentStop`,
`PreTaskExec`, `PostTaskExec`, `PostFileCreate`, `PostFileUpdate`

**Note on SessionStart:** Survey (2026-07-18) stated SessionStart absent. 2026-07-20
re-verification at kiro.dev/docs/hooks confirms **SessionStart IS present** (10 events
including it). Previous absence claim was incorrect; this supersedes it.

**Inject mechanism:**
Shell stdout → context (placement needs live-test to confirm inject is model-visible
vs UI display only). Hook scripts are executables; Kiro passes payload via stdin.
`PreToolUse` is blocking (can halt execution). `Stop`/`AgentStop` = non-blocking POST.

- `SessionStart` → shell stdout → context (live-test: confirm placement)
- `UserPromptSubmit` → shell stdout → context (live-test: confirm same-turn inject)
- `PostToolUse` → full stdin payload; capture to yadgar action log
- `PreToolUse` → blocking; decision-gate (allow/block tool call)
- `Stop` / `AgentStop` → non-blocking POST
- No `PreCompact` event (confirmed absent in Kiro docs)

**Specs persistence note:** `.kiro/specs/` (requirements.md + design.md + tasks.md)
is an S4 analog. Persistence across sessions is unverified in live environment.

## Build scope

Wire in `hooks_render.py` replacing Kiro `_emit_stub`:

1. `SessionStart` → `yadgar hook sessionStart`; return stdout to context
2. `UserPromptSubmit` → `yadgar hook userPromptSubmit`; return stdout to context
3. `PostToolUse` → `yadgar hook postToolUse` (stdin = payload); no return needed
4. `PreToolUse` → `yadgar hook preToolUse` (stdin = payload); return allow/block

Hook JSON files written to `.kiro/hooks/yadgar-session.json`, `yadgar-capture.json`.

Rules file: `.kiro/steering/yadgar.md` carrying the yadgar contract.
AGENTS.md global path for Kiro: compatible; check `~/.kiro/AGENTS.md` (unverified —
open question).

Specs integration (S4): out of scope v1. Revisit if persistence is confirmed.
